# Laravel API Security Checklist

> Версия 2.0 · lexio (см. детали в SECURITY_PLAYBOOK.md, раздел 0 — обязательный ритуал после AI-сессий)

## После каждого сеанса вайбкодинга

### 1. Проверка авторизации
- [ ] Нельзя получить доступ к приватным API без токена.
- [ ] Проверены все middleware.
- [ ] Нет публичных admin endpoint.

### 2. Broken Access Control (IDOR)
- [ ] Пользователь может работать только со своими ресурсами.
- [ ] Все запросы проверяют owner_id/organization_id.

### 3. Mass Assignment
- [ ] Используются `$fillable`.
- [ ] Нет `$guarded = []`.
- [ ] Не передается `$request->all()` напрямую.

### 4. SQL Injection
- [ ] Нет `DB::raw()` с пользовательским вводом.
- [ ] Нет `whereRaw()` с конкатенацией.
- [ ] Используются параметры Query Builder/Eloquent.

### 5. XSS
- [ ] API не возвращает неочищенный HTML без необходимости.
- [ ] SVG проверяются отдельно.

### 6. Загрузка файлов
- [ ] Проверяется MIME и сигнатура файла.
- [ ] Ограничен размер.
- [ ] Генерируется случайное имя.
- [ ] Файлы не исполняются сервером.

### 7. SSRF
- [ ] Запрещены localhost/127.0.0.1/169.254.169.254.
- [ ] Только http/https.

### 8. Docker
- [ ] APP_DEBUG=false.
- [ ] .env не попадает в образ.
- [ ] Контейнеры работают без root при возможности.

### 9. Очереди/кеш/сокеты
- [ ] Сейчас: sync/array-драйверы, внешних сервисов нет — при появлении Redis/очередей вернуться к полному чек-листу (пароль, закрытые порты, ACL).
- [ ] `docker compose ps` — наружу торчит только нужное (nginx :8080).

### 10. Laravel
- [ ] APP_KEY заполнен.
- [ ] composer audit выполнен.
- [ ] npm audit выполнен.
- [ ] php artisan optimize выполнен.
- [ ] Логи не содержат секретов.

### 11. HTTP Security
- [ ] HTTPS.
- [ ] HSTS.
- [ ] CSP.
- [ ] X-Frame-Options.
- [ ] X-Content-Type-Options.
- [ ] Referrer-Policy.

### 12. Rate Limit
- [ ] Login.
- [ ] Register.
- [ ] Password reset.
- [ ] OTP.
- [ ] File upload.

### 13. Перед релизом
- [ ] Все тесты прошли.
- [ ] Проверен CORS.
- [ ] Проверены очереди (пока sync — пропуск с пометкой).
- [ ] Проверены резервные копии (sqlite-файл БД!).
- [ ] Проверены секреты GitHub Actions.
